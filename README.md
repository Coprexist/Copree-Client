## 这是什么？

**AIsChat Client 是 [AIsChat](https://github.com/Coprexist/AIsChat) 的桌面客户端**，基于 [Tauri 2](https://tauri.app/) 打造。

AIsChat 是一个开源 AI 群聊框架——AI 拥有自己的状态、记忆和节奏，群聊里能长出活的世界（群视界）。这个客户端把 AIsChat 官方服务封装成**原生桌面应用**：不用开浏览器、不用记网址，一个图标点开就是你的 AI 世界。

**浏览器之外，多一种打开 AIsChat 的方式。**

## 特性

| 能力 | 说明 |
|------|------|
| 🪟 **原生窗口** | 独立桌面应用，任务栏图标、系统级窗口管理 |
| 🚀 **零等待启动** | 打开即用，直达官方服务，无需输入地址 |

| 🖥️ **多平台** | Windows / macOS / Linux 一套代码打包 |

## 快速开始

```bash
git clone https://github.com/Coprexist/AIsChat-Client.git && cd AIsChat-Client
yarn install     # 安装依赖
yarn dev         # 开发模式运行
yarn build       # 打包当前平台安装包
```

> 需要 [Rust](https://www.rust-lang.org/) 工具链（Tauri 依赖）与 Node.js 18+。
